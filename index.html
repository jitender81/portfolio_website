AUTOMATED CI/CD WORKFLOW

Jenkins CI/CD with Webhooks & SonarQube Quality Gates

Every commit pushed to GitHub automatically triggers a Jenkins pipeline through configured webhooks. The workflow runs automated tests, passes code through SonarQube quality analysis, builds optimized Docker container images, pushes them to DockerHub, and triggers zero-downtime deployment.

  • GitHub Webhook triggers Jenkins automated pipeline on every push
  • SonarQube code quality and vulnerability analysis quality gates
  • Multi-stage Docker container builds pushed directly to DockerHub registry
  • Automated deployment execution with health verification
CLOUD & INFRASTRUCTURE

AWS EC2, Kubernetes, Terraform & Nginx Reverse Proxy

The stack is deployed on an AWS EC2 compute instance with Kubernetes container orchestration and declarative Terraform IaC. Traffic is routed via Nginx reverse proxy with SSL/TLS secured via Let’s Encrypt + Certbot, backed by cloud-managed MongoDB Atlas.

  • Full-Stack Architecture: React/Vite UI with high-speed FastAPI Python backend
  • MongoDB Atlas for managed cloud database persistence
  • Terraform Infrastructure as Code for reproducible provisioning
  • Nginx reverse proxy with custom subdomain & automated Let’s Encrypt HTTPS/SSL
OBSERVABILITY & MONITORING

Prometheus, Node Exporter & Grafana Dashboards

End-to-end telemetry scraping collects infrastructure resource stats via Node Exporter and application response times via Prometheus, rendered in real-time on customized Grafana dashboards.

  • Node Exporter capturing host CPU, memory, disk I/O & network metrics
  • Prometheus time-series scraper collecting container & application telemetry
  • Grafana visualization dashboards for live cluster & health metrics
  • Proactive alerting thresholds for error rates and resource saturation
